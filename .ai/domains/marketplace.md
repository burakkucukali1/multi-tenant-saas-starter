# Marketplace Domain Rules

## Domain Overview

Marketplace systems connect:

Buyers

↓

Platform

↓

Sellers

---

# Multi-Sided Architecture

Never assume a single user type.

Common actors:

- Buyer
- Seller
- Admin

---

# Ownership

Resources must define ownership.

Listing
→ Seller

Order
→ Buyer + Seller

Payout
→ Seller

---

# Payments

Payments are critical systems.

Avoid optimistic updates.

Server confirmation required.

---

# Transactions

Use transactional workflows.

Important flows:

- Purchase
- Refund
- Cancellation
- Payout

---

# Auditability

Track:

- Orders
- Payments
- Refunds
- Payouts

---

# Search

Search quality is a core business feature.

Optimize for:

- Filtering
- Ranking
- Discoverability

---

# Review Checklist

- Is ownership clear?
- Are transactions safe?
- Are payments verified?
- Is audit logging present?
